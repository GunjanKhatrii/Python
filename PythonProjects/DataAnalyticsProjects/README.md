## 📽️ YouTube Data Analysis


### 🎯 Objective
Analyze YouTube comments to uncover patterns in sentiments, emoji usage, and wording usage.

### 🛠️ Technologies Used
- **Data Collection:** YouTube Data via kaggel
- **Analysis:** Pandas, NumPy, SciPy
- **Visualization:** Matplotlib, Seaborn, WordCloud
- **NLP:** NLTK, TextBlob for sentiment analysis

### 📊 Key Insights Discovered
- Peak upload times for maximum engagement
- Correlation between video length and view retention
- Category-wise performance analysis
- Sentiment analysis of video titles and descriptions
- Regional trending patterns
